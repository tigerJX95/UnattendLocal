# 繁體中文用詞建議

本表以繁體中文示範如何整理翻譯術語，可作為翻譯和校對的參考。涉及 Windows 正式選項時，請以對應版本的繁體中文 Windows 畫面為準。

| 简体源文 | 建議譯法 |
| --- | --- |
| 文件 | 檔案 |
| 文件夹 | 資料夾 |
| 软件 | 軟體 |
| 硬件 | 硬體 |
| 设置 | 設定 |
| 配置方案 | 設定方案 |
| 导入 / 导出 | 匯入 / 匯出 |
| 保存 | 儲存 |
| 预览 | 預覽 |
| 账户 | 帳戶 |
| 密码 | 密碼 |
| 网络 | 網路 |
| 计算机名 | 電腦名稱 |
| 磁盘 / 分区 | 磁碟 / 磁碟分割 |
| 格式化 | 格式化 |
| 清空磁盘 | 清除磁碟上的全部資料 |
| 只读 | 唯讀 |
| 默认 | 預設 |
| 启用 / 禁用 | 啟用 / 停用 |
| 驱动程序 | 驅動程式 |
| 任务栏 | 工作列 |
| 锁屏 | 鎖定畫面 |
| 资源管理器 | 檔案總管 |

保留 `Windows`、`XML`、`JSON`、`PowerShell`、`AppLocker`、`WinPE` 等產品名稱和技術識別字。風險提示應明確指出影響範圍，涉及資料清除的句子請人工複核。
