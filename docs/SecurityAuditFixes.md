# V1.12.1 安全审计修复说明

日期：2026-10-21。基于已交付的 V1.12 恢复源码修复，不改变原作者的脚本阶段分类，不增加自动登录与隐私文件保留的联动。

| 审计项 | 修复方式 | 验证重点 |
|---|---|---|
| F01 原生密码预览泄露 | 补齐全部原生 Credentials/Password 节点遮蔽；提示自定义脚本敏感内容需自行核对 | 实际安装导出保留合成密码，预览无该密码 |
| F02 无关脚本被改写 | 比较视图仅用于识别，转换只回写旧版移除辅助文件与完整已识别移除命令块 | 仅取消计算器移除时，自定义双反斜杠字符串保留；兼顾换行形式 |
| F03 反向值误映射 | 使用固定生成器建立完整功能模板，检查命令、值、阶段与辅助文件；未知内容保留并提示 | HiberbootEnabled=/d 1 不映射为关闭快速启动；20 项正常开关仍能识别；旧还原记录不能覆盖实际命令值 |
| F04 忽略执行顺序 | 按数字 Order 核对提取/调用，以及默认用户配置单元加载、脚本、卸载顺序；重复、越界值不作为有效管线 | 颠倒、重复、越界 Order 不误映射；XML 节点排列不同但数字顺序正确仍可识别 |
| F05 直接覆盖保存 | 同目录临时文件完成写入及刷盘后替换目标；失败不回退到直接覆盖 | 注入部分写入后异常，旧文件不变；首次写入与最终替换失败不留下半份目标文件 |
| F06 账户控制字符 | 导出前拒绝控制字符，返回具体账户名称和索引 | 制表符、换行、回车及其他控制字符定位到 Users.Name |

专项测试位于 `Tests/SecurityAuditFixTests.cs`，共 49 项。完整回归也调用该组测试；可以使用 `--security-audit-only` 单独运行。

导入识别允许已知脚本包装器末尾保留不相关的附加内容，不会仅因这一差异丢失已有开关；未知或冲突命令仍保留原文，不能可靠合并时阻止导出。

两种最终 EXE 的原生产品版本均为 1.12.1，文件版本均为 1.12.1.0。还从各 EXE 中提取实际打包的核心程序集，分别执行上述 49 项测试，均通过。

本轮使用 Linux 上的 .NET 工具链编译、进行模型回归和模拟写入故障。没有运行 Windows 原生 WPF 窗口或实际 Windows 安装；本机验收步骤见根目录 `VisualStudio使用说明.md`。原始审计报告中的发现不再代表这些修复后的具体实现，但本次修复也不构成对全部安全性的保证。

同版本提示修正：后续将计算机命名脚本的长度提示明确为“最多 65,536 个字符”，限制不变；重新发布并核对了新提示及版本。本页 49 项专项结果记录安全修复完成时的验证，不表示提示修正后再次执行。
