一、用途与授权

UnattendLocal 用于在本地准备 Windows 安装应答文件。请仅对本人设备，或已取得明确授权的设备和数据使用。Windows、软件、密钥与安装介质的使用授权由相应权利人规定；本工具不提供 Windows 激活授权，也不代替软件许可。

二、安装、磁盘与脚本

生成或导出文件本身不操作目标磁盘。将配置用于安装后，分区、格式化、应用移除、策略与脚本会按配置作用于目标系统，可能造成数据丢失或影响系统使用。请先备份重要数据、核对目标磁盘与分区，并在虚拟机验证。自定义脚本的操作范围可能超出界面中的摘要；工具不在当前电脑执行这些脚本。

三、凭据与文件保管

应答 XML、无线配置、保存的方案与自定义脚本可能包含账户密码、Wi-Fi 密码、产品密钥、令牌等敏感内容。Base64 是可还原的编码，不是加密。预览会遮蔽部分已识别凭据，但不代表实际导出文件、原文或自定义脚本已被全面脱敏。分享前请核对完整内容。

“保留安装隐私文件”控制原生成核心对指定文件的清理，不控制自定义脚本内另写的删除命令，也不清理安装介质上的原始文件。当前核心要求预设本地账户时，自动清理搭配首次自动登录；关闭自动登录须手动选择保留，程序不会代为勾选。

四、离线使用与导入配置

编辑、保存、生成配置和查看本说明可离线进行。配置中的联网下载、微软账户登录或其他联网脚本是否访问网络，取决于配置与目标安装环境。导入 XML 中的未知内容会尽量保留；结构检查与配置预览不构成对脚本安全性或目标系统兼容性的完整审核。请仅使用可信来源并核对原文。
