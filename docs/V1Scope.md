# 功能范围

UnattendLocal 以固定 UnattendGenerator 核心为基础，提供常用 Windows 安装选项的中文本地界面、可复用 JSON 方案、XML 导入、检查与导出。

包含账户与首次登录、语言区域、镜像分区、Wi-Fi、单网卡静态 IPv4/IPv6、系统与外观、应用移除、自定义脚本、快捷预设、额外 XML 组件及应答文件 ISO 封装。未知 XML 按可识别范围保留原文，不能可靠合并时阻止导出。支持范围不代表覆盖原作者全部高级设置；完整自定义 PE、多网卡与高级网络策略需按具体场景另行配置。

当前源码来源与选择性同步见 UPSTREAM.md，导出格式及介质使用见 AnswerFileExport.md。
