# 设置搜索 / Settings search

点击顶部放大镜或按 Ctrl+F，输入中英文名称或关键词；多个关键词使用空格分隔，支持全角字符规范化。

Click the toolbar magnifier or press Ctrl+F. Enter a Chinese or English name or keywords, separated by spaces.

结果显示设置名称、页面和说明。点击结果或按 Enter 后切页、滚动定位并高亮约四秒。方向键可选择结果，Esc 关闭。再次打开保留本次会话的搜索词。

Results show the setting, page and description. Click or press Enter to navigate and highlight for about four seconds. Use arrow keys to select and Esc to close. The query is retained for this session.

搜索不自动启用设置。被当前模式隐藏的编辑器会定位到可见的所属区域，并在状态栏说明。应用移除条目会更新该页筛选，不改变勾选。

Search does not enable settings. Editors hidden by the current mode lead to a visible containing section with a status message. App-removal results update the page filter without changing selections.

搜索只使用内置标签与说明，不检索账户密码、Wi-Fi 密码、策略原文或脚本内容。

Search uses built-in labels and descriptions, not account passwords, Wi-Fi secrets, policy text or script contents.
