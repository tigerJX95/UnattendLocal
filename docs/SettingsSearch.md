# 设置搜索 / Settings search

点击顶部放大镜或按 Ctrl+F，输入中英文名称或关键词；多个关键词使用空格分隔，支持全角字符规范化。分类可选全部设置或某个页面；留空关键词会列出所选分类的设置。

Click the toolbar magnifier or press Ctrl+F. Enter Chinese or English names or keywords separated by spaces. Choose all categories or a specific page; an empty query lists settings in the selected category.

结果显示设置名称、页面和说明。点击结果或按 Enter 后切页、滚动定位并高亮约四秒。输入框中的方向键可选择结果，Ctrl+L 返回输入框并全选，Esc 关闭。分类下拉框的 Enter 用于确认分类，不触发定位。再次打开保留本次会话的搜索词与分类；关闭主程序后不保留。

Results show the setting, page and description. Click or press Enter to navigate and highlight for about four seconds. Use arrow keys from the query box to select a result, Ctrl+L to select the query for editing, and Esc to close. Enter inside the category selector confirms the category rather than navigating. Reopening retains the query and category for this application session.

清空图标同时清除关键词并恢复全部分类。未匹配时停用定位按钮；分类内无结果不会自动扩展范围，提示可切换全部分类。连续输入采用短暂延迟刷新，确认定位时先刷新最新关键词；输入法选词期间不接管 Enter。

Reset clears the query and restores all categories. Navigation is disabled when nothing matches. An empty scoped result does not silently broaden the search; a message suggests returning to all categories. Consecutive typing uses a short refresh delay; navigation flushes the latest query. Enter is left to the input method during composition.

搜索不自动启用设置。被当前模式隐藏的编辑器会定位到可见的所属区域，并在状态栏说明。应用移除条目会更新该页筛选，不改变勾选。

Search does not enable settings. Editors hidden by the current mode lead to a visible containing section with a status message. App-removal results update the page filter without changing selections.

搜索只使用内置标签与说明，不检索账户密码、Wi-Fi 密码、策略原文或脚本内容；关键词和分类不写入 JSON 方案或 XML。

Search uses built-in labels and descriptions, not account passwords, Wi-Fi secrets, policy text or script contents. The query and category are not written to JSON plans or XML.
